Infrastructure Testing Checklist
1. Outbound Egress / Cloud NAT

When VMs run without public external IPs, they require Cloud NAT to reach the external Open-Meteo API. Watch the green/yellow banner above to verify egress connectivity.

2. Load Balancer Distribution

Deploy this app across a Managed Instance Group (MIG). Refresh the page through the Load Balancer IP to observe the Serving Instance hostname switch between VM instances.

3. Health Checks & Monitoring

Configure your Load Balancer Health Check on HTTP /health on port 8080 (or 80). Monitor uptime and system load telemetry.
