1.2 Cloud IAM (Roles, Groups & Service Accounts)

Role Type Description ACE Exam Recommendation
Basic / Primitive Viewer, Editor, Owner. Broad legacy roles applying to the entire project. Avoid in production. Violates the principle of least privilege.
Predefined Created and maintained by Google for each service (e.g., roles/storage.objectViewer, roles/compute.instanceAdmin.v1). Best practice. Highly granular and automatically kept up to date by Google.
Custom User-created roles with an exact list of elementary permissions (e.g., compute.instances.start). Use only if no predefined role meets the need. Cannot be applied at the Folder level.
💡
Golden Exam Rule — Google Groups for IAM: Never assign IAM roles directly to individual user email addresses. Create a Google Group (e.g., backend-devs@company.com), grant the role to the group, then manage membership inside that group.

Compute Engine: Best Practices

  • Machine Families: E2 (cost-effective, balanced), N2 (general-purpose baseline), C2 (compute-optimized for high CPU workloads), M2 (ultra-high memory up to 12 TB for SAP HANA).
  • Incremental Snapshots: Stored multi-regionally in Cloud Storage by default, ensuring maximum disaster recovery tolerance.

Managed Instance Groups (MIGs)

  • Instance Template: Immutable blueprint used to instantiate and scale identical VMs.
  • Autohealing: Automatically reboots or recreates a VM instance if the application HTTP Health Check fails.
  • Autoscaling: Automatically adds or removes VM instances based on CPU utilization or load balancer metrics.
💰
Spot VMs (formerly Preemptible): Instances offering discounts of 60% to 91%. Google can terminate them at any time with a 30-second warning. Perfect for batch processing, video rendering, or secondary GKE node pools. Never use for stateful production databases!

GKE Standard vs GKE Autopilot

  • GKE Standard: You select the VM types, disk sizes, and node OS images. You pay for underlying VMs whether fully loaded or idle.
  • GKE Autopilot (Recommended): Google fully manages node infrastructure, security hardening, and OS patches. You only pay for the CPU and memory resources requested by your Pods.

App Engine: Standard vs Flexible

  • Standard: Pure code deployment within a sandboxed runtime. Millisecond boot time, full scale to zero during idle periods.
  • Flexible: Runs custom Docker containers on Compute Engine VMs. Allows SSH access and native OS background libraries, but does not scale to zero (minimum 1 VM billed continuously).

Object Storage (Cloud Storage) & Analytics

Storage & Big Data

4.1 Cloud Storage (GCS): Classes & Lifecycle Management

Storage Class Minimum Duration Access Frequency Exam Use Case
Standard None Frequent (daily) Active data, websites, regularly accessed media assets.
Nearline 30 days < 1 time per month Monthly data backups, periodic analytical reports.
Coldline 90 days < 1 time per year Disaster recovery (DR) plans, annual archives rarely read.
Archive 365 days Almost never Long-term legal and regulatory compliance (5 to 10 years) at minimum cost.
⏳
Lifecycle Management Rules: Define automated rules: for example, transition objects to Nearline after 30 days, to Archive after 90 days, and permanently delete after 365 days.

4.2 BigQuery, Dataflow & Pub/Sub

Pub/Sub

Fully managed global asynchronous messaging bus. Decouples message producers and consumers with Pull or Push subscriptions.

Dataflow

Unified streaming (real-time) and batch processing engine powered by Apache Beam. Provides automatic worker autoscaling.

BigQuery

Serverless petabyte-scale data warehouse executing standard SQL queries. Optimize costs using Partitioning (by date) and Clustering.

Networking, VPC, Load Balancing & Security

Network & Perimeter

6.1 Global VPC Architecture & Shared VPC

🌐
Google Cloud VPC is GLOBAL: Unlike other cloud providers where a VPC is confined to a single region, a GCP VPC spans the entire globe. Only Subnets are regional. Two VMs located in completely different continents on the same VPC communicate privately via internal IP addresses across Google's private fiber backbone without ever traversing the public Internet!

Shared VPC

Enables an enterprise organization to connect multiple projects to a centralized shared network. Managed centrally from a Host Project (administered by the network team) and consumed by Service Projects (used by development application teams).

VPC Network Peering

Privately connects two independent VPC networks without VPN gateways or external IP routing. Critical exam note: VPC Peering is non-transitive (if VPC A peers with VPC B and VPC B peers with VPC C, VPC A cannot communicate directly with VPC C).

6.2 Cloud Firewall & Cloud IAP

  • Stateful Firewall: If an inbound connection is allowed, the corresponding outbound response traffic is automatically permitted without additional rules.
  • Rule Priorities: Ranges from 0 (highest priority) to 65535 (default lowest catch-all priority).
  • Recommended Targeting: Apply firewall rules via Network Tags or, for superior security, via attached Service Accounts.
  • Cloud IAP (Identity-Aware Proxy): Establish secure SSH and RDP administrative sessions to VMs without public IP addresses and without VPN gateways through IAM-authenticated encrypted tunnels.

6.3 Cloud Load Balancing

Load Balancer Type Scope OSI Layer Key Capabilities
External Application LB (HTTP/S) Global Layer 7 (HTTP/HTTPS) Single global Anycast IP address. Client SSL termination, URL path-based routing, Cloud CDN and Cloud Armor (WAF/DDoS defense) integration.
External Network LB Regional Layer 4 (TCP/UDP) Ultra-fast transparent pass-through without proxying. Original client source IP address is fully preserved.
Internal Application / Network LB Regional Layer 7 or Layer 4 Private internal load balancing designed for backend microservices and inter-tier VM communication.

DevOps, Deployment & Observability

CI/CD & Monitoring

7.1 CI/CD & Deployment Services

Cloud Build

Serverless CI/CD automation platform. Executes builds defined in a cloudbuild.yaml configuration file or Dockerfile. Triggered automatically on GitHub/GitLab repository commits.

Artifact Registry

Modern successor to Container Registry. Centrally stores and manages Docker OCI container images and package dependencies (npm, Maven, Python) with automated vulnerability scanning.

Terraform / Deployment Mgr

Infrastructure as Code (IaC) to declaratively provision, manage, and version-control your entire Google Cloud resource estate.

ACE Exam Reflex Anti-Traps Cheat Sheet

Exam Special
If the question mentions... The correct answer must contain... The trap to avoid
"Preventing accidental deletion of a production project even by an Owner" Project Lien (resourcemanager.projects.delete) Do not propose removing the Owner role (a Lien protects against deletion even by Owners).
"Assigning access to a team of 15 developers" Create a Google Group and assign a Predefined role to the group Never assign IAM roles directly to individual user accounts.
"Stateless containerized application with unpredictable traffic swings from 0 to 10,000 req/s" Cloud Run (scale to zero and instantaneous scaling) Do not choose Compute Engine or GKE which require paying for continuously running compute VMs.
"Relational SQL database requiring 99.999% SLA and worldwide multi-region scalability" Cloud Spanner Cloud SQL does not scale horizontally and is confined to a single region.
"SSH administrative access to a Compute Engine VM with no public IP address and no VPN" Cloud IAP (Identity-Aware Proxy) Do not deploy an exposed Bastion host instance with an external public IP.
"Retaining audit logs for 7-year legal compliance at the lowest possible cost" Log Sink to Cloud Storage (Coldline or Archive class) Do not retain logs in Cloud Logging or BigQuery, which are significantly more expensive.
"Fault-tolerant batch processing or 3D rendering job requiring maximum cost reduction" Spot (Preemptible) VMs Do not use reserved or on-demand standard VM instances at full price.
"Allowing an external third-party customer to download a private GCS file without a Google account" Signed URL (temporary pre-signed URL with an expiration period) Never grant public read access to the entire storage bucket.
